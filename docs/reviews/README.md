## How to use

Reviews are historical artifacts. The authoritative spec is
`docs/behavior-spec.md` and the implementation plan is `PLAN.md`. If a review
conflicts with the current code, trust the code + PLAN.md — the reviews were
snapshots and the plan was updated after each round.
