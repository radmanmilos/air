# Example 1: Full Agent Task Execution

This example demonstrates the autonomous ReAct loop that plans and executes tasks independently.

## Run the Command

```bash
mgai run "Find all Python files larger than 10KB and list them"
```

## How It Works

1. **Plan**: The agent (qwen3.5:4b) breaks the goal into steps using `planner.py`
2. **Think**: Decides which tools to use (files, shell, web, memory)
3. **Act**: Executes tools sequentially with retry logic
4. **Reflect**: Checks results against expected output format
5. **Refine**: Iterates if necessary until task complete

## Expected Output Format

The agent returns a structured result containing:
```json
{
  "task": "Find all Python files larger than 10KB",
  "steps": [
    {
      "action": "list_dir",
      "params": {"recursive": false},
      "success": true
    },
    {
      "action": "search_files",
      "params": {"pattern": "\\.py$"},
      "success": true
    }
  ],
  "result": ["src/core/ollama_client.py", "tests/test_router.py"]
}
```

## Advanced Configuration

Edit `config.yaml` to adjust agent behavior:
- `max_retries`: Number of retry attempts per step (default: 3)
- `timeout_seconds`: Timeout for each action (default: 60s)
- `sandbox_cwd`: Working directory constraint (e.g., "src/")
