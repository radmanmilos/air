# MGAI Documentation

## Overview

MGAI (Makeing Good AI) is a unified multi-model LLM system with integrated tools for file operations, shell commands, web access, memory (RAG), and multimodal capabilities (vision, speech). Built to enable autonomous agents that can work end-to-end on complex tasks.

## Key Features

- **Multi-Model Architecture**: qwen3.5:4b (primary brain with vision/tools), nomic-embed-text (for RAG)
- **Tool Integration**: Files, Shell, Web, Memory operations
- **Multimodal**: Vision, Speech-to-Text, Text-to-Speech
- **Self-Improvement**: Safe autonomous code modification with guardrails
- **API Interface**: REST API and web dashboard
